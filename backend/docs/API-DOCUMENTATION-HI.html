1. Base URL

http://localhost:5000/api

Health check endpoint:

GET /api/health

2. Common Response Format

{
  "success": true,
  "message": "Project created successfully",
  "data": {}
}

3. Authentication Flow

  • Login ke baad accessToken response me milta hai.
  • refreshToken secure HTTP-only cookie me milta hai.
  • Protected routes me Authorization: Bearer <token> bhejna hota hai.
  • Frontend me credentials: "include" ya withCredentials: true use karo.

4. Auth APIs

POST /api/auth/login

{
  "email": "admin@ephonon.com",
  "password": "ChangeThisPassword123!"
}

POST /api/auth/register

Protected route. Sirf admin naya CMS user bana sakta hai.

{
  "name": "Content Manager",
  "email": "editor@ephonon.com",
  "password": "StrongPassword123!",
  "role": "editor"
}

POST /api/auth/logout

Bearer token required.

POST /api/auth/refresh

Refresh token cookie ke basis par naya access token deta hai.

GET /api/auth/profile

Logged-in user profile fetch karta hai.
